Frequently Asked Questions

Does GigScore store raw bank statements or transaction histories?

No. Mock Account Aggregator payouts are processed strictly in memory to compute the 8 behavioral features and run the 5 authenticity checks. Only the derived score, reason codes, and audit metadata are persisted.

What happens if the trained XGBoost artifact is missing?

GigScore never silently switches models. If the calibrated XGBoost artifact is absent, the API evaluates using the monotonic Rule-Based Scorecard and explicitly reports model_version="rule-scorecard-v1.0" and scoring_engine="rule_scorecard".

What happens when a worker profile is flagged by the Authenticity Engine?

If claimed vs. bank-verified credits diverge, round-number ratios are suspicious, duplicate payouts appear, or an impossible single-month spike occurs, GigScore returns authenticity_status="NEEDS_REVIEW", generates no credit score (gig_score: null), and charges ₹0 to the lender.
